1. Convenciones

El estado del registro se escribe |q₀q₁q₂⟩, con q₀ como bit más significativo. Un estado general es

|ψ⟩ = Σₓ αₓ |x⟩, x ∈ {000, 001, …, 111}, Σₓ |αₓ|² = 1

La entrada del circuito es un estado producto |ψ₀⟩ = |a⟩ ⊗ |b⟩ ⊗ |c⟩ = |abc⟩ con a, b, c ∈ {0, 1}. Por linealidad, el resultado para cualquier superposición de entrada se obtiene sumando los resultados de las entradas base con sus amplitudes.

2. Operadores de cada paso

U₁ = U₂ = I ⊗ H ⊗ I (Hadamard sobre q₁) U₃ = I ⊗ I ⊗ H (Hadamard sobre q₂) U₄ = CCX(q₀,q₁ → q₂) = (I₈ − |11⟩⟨11| ⊗ I) + |11⟩⟨11| ⊗ X |a,b,c⟩ ↦ |a, b, c ⊕ ab⟩ (intercambia |110⟩ ↔ |111⟩) U₅ = I ⊗ CZ(q₁ → q₂) = I ⊗ (|0⟩⟨0| ⊗ I + |1⟩⟨1| ⊗ Z) |a,b,c⟩ ↦ (−1)^(bc) |a,b,c⟩ = diag(1, 1, 1, −1, 1, 1, 1, −1) |ψₖ⟩ = Uₖ |ψₖ₋₁⟩, k = 1, …, 5

3. Desarrollo general para la entrada |abc⟩

Paso 1 · H sobre q₁

|ψ₁⟩ = (I ⊗ H ⊗ I)|a⟩|b⟩|c⟩ = |a⟩ ⊗ (1/√2)(|0⟩ + (−1)ᵇ|1⟩) ⊗ |c⟩ = (1/√2)( |a0c⟩ + (−1)ᵇ |a1c⟩ )

Paso 2 · H sobre q₁

|ψ₂⟩ = |a⟩ ⊗ (1/√2)( H|0⟩ + (−1)ᵇ H|1⟩ ) ⊗ |c⟩ = |a⟩ ⊗ (1/2)[ (|0⟩ + |1⟩) + (−1)ᵇ(|0⟩ − |1⟩) ] ⊗ |c⟩ = |a⟩ ⊗ (1/2)[ (1 + (−1)ᵇ)|0⟩ + (1 − (−1)ᵇ)|1⟩ ] ⊗ |c⟩ = |a⟩|b⟩|c⟩ = |abc⟩ (porque H·H = I)

Paso 3 · H sobre q₂

|ψ₃⟩ = |a⟩|b⟩ ⊗ (1/√2)(|0⟩ + (−1)ᶜ|1⟩) = (1/√2)( |ab0⟩ + (−1)ᶜ |ab1⟩ )

Paso 4 · Toffoli (controles q₀, q₁; objetivo q₂)

Si ab = 0 el estado no cambia. Si a = b = 1 se aplica X a q₂:

X · (1/√2)(|0⟩ + (−1)ᶜ|1⟩) = (1/√2)(|1⟩ + (−1)ᶜ|0⟩) = (−1)ᶜ · (1/√2)(|0⟩ + (−1)ᶜ|1⟩) ⇒ |ψ₄⟩ = (−1)^(abc) · |a⟩|b⟩ ⊗ (1/√2)(|0⟩ + (−1)ᶜ|1⟩)

La Toffoli solo introduce una fase global −1 cuando a = b = c = 1 (porque X|−⟩ = −|−⟩).

Paso 5 · CZ (control q₁, objetivo q₂)

Si b = 0 el estado no cambia. Si b = 1 se aplica Z a q₂:

Z · (1/√2)(|0⟩ + (−1)ᶜ|1⟩) = (1/√2)(|0⟩ − (−1)ᶜ|1⟩) = (1/√2)(|0⟩ + (−1)^(c+1)|1⟩) ⇒ |ψ₅⟩ = (−1)^(abc) · |a⟩|b⟩ ⊗ (1/√2)(|0⟩ + (−1)^(b⊕c)|1⟩) = (−1)^(abc) · (1/√2)( |ab0⟩ + (−1)^(b⊕c) |ab1⟩ )

Paso 6 · Medición de q₁

P(q₁ = k) = ‖(I ⊗ |k⟩⟨k| ⊗ I)|ψ₅⟩‖² P(q₁ = b) = |1/√2|² + |1/√2|² = 1, P(q₁ = 1 − b) = 0 Estado tras medir: |ψ'⟩ = |ψ₅⟩ (q₁ ya estaba en el estado definido |b⟩) Colapso del registro completo: P(|ab0⟩) = 1/2, P(|ab1⟩) = 1/2
Resultado general. |abc⟩ ⟶ (−1)^(abc) · |a⟩ ⊗ |b⟩ ⊗ H|b ⊕ c⟩. Las dos Hadamard sobre q₁ se cancelan, por lo que la medición de q₁ devuelve siempre el valor inicial b con probabilidad 1. El qubit q₂ termina en |+⟩ si b = c y en |−⟩ si b ≠ c.

4. Ejemplos desarrollados

Entrada |000⟩

|ψ₀⟩ = |000⟩ = (1, 0, 0, 0, 0, 0, 0, 0)ᵀ |ψ₁⟩ = (I⊗H⊗I)|000⟩ = (1/√2)(|000⟩ + |010⟩) = (1/√2)(1, 0, 1, 0, 0, 0, 0, 0)ᵀ |ψ₂⟩ = (1/√2)[ (1/√2)(|000⟩ + |010⟩) + (1/√2)(|000⟩ − |010⟩) ] = |000⟩ |ψ₃⟩ = (I⊗I⊗H)|000⟩ = (1/√2)(|000⟩ + |001⟩) = (1/√2)(1, 1, 0, 0, 0, 0, 0, 0)ᵀ |ψ₄⟩ = CCX|ψ₃⟩ = (1/√2)(|000⟩ + |001⟩) (q₀ = 0: la Toffoli no actúa) |ψ₅⟩ = CZ|ψ₄⟩ = (1/√2)(|000⟩ + |001⟩) (q₁ = 0: la CZ no actúa) Medición de q₁: P(q₁=0) = 1/2 + 1/2 = 1, P(q₁=1) = 0 Colapso: P(|000⟩) = 50 %, P(|001⟩) = 50 %

Entrada |111⟩

|ψ₀⟩ = |111⟩ |ψ₁⟩ = |1⟩ ⊗ (1/√2)(|0⟩ − |1⟩) ⊗ |1⟩ = (1/√2)(|101⟩ − |111⟩) |ψ₂⟩ = (1/√2)[ (1/√2)(|101⟩ + |111⟩) − (1/√2)(|101⟩ − |111⟩) ] = |111⟩ |ψ₃⟩ = |11⟩ ⊗ (1/√2)(|0⟩ − |1⟩) = (1/√2)(|110⟩ − |111⟩) |ψ₄⟩ = CCX|ψ₃⟩ = (1/√2)(|111⟩ − |110⟩) = (1/√2)(−|110⟩ + |111⟩) |ψ₅⟩ = CZ|ψ₄⟩ = (1/√2)(−|110⟩ − |111⟩) = −(1/√2)(|110⟩ + |111⟩) (|111⟩ cambia de signo) Medición de q₁: P(q₁=1) = 1/2 + 1/2 = 1, P(q₁=0) = 0 Colapso: P(|110⟩) = 50 %, P(|111⟩) = 50 %
